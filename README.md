## 🚀 How to Bind to Render

1. Log in to [Render Dashboard](https://dashboard.render.com/).
2. Click **New +** and select **Static Site** (or use the Blueprint button above).
3. Connect your GitHub account and select the **`nova-cuts`** repository:
   - **Repository:** `https://github.com/shrihari12012007-web/nova-cuts`
   - **Branch:** `main`
   - **Build Command:** *(Leave empty)*
   - **Publish Directory:** `.` *(Current directory)*
4. Click **Create Static Site**.
5. Render will automatically deploy your site and provide your custom live `.onrender.com` URL!
