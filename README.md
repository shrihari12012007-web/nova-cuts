# NOVA CUTS — Modern Barber Studio & Booking Platform

NOVA CUTS is a modern, high-conversion web application and appointment booking interface for a premium barber studio, built with responsive HTML5, modern CSS3 animations, and vanilla JavaScript. Featuring an interactive service catalog, live barber scheduling workflows, instant client review showcases, and single-click continuous deployment configured for Render.
